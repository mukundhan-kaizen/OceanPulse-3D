# 🌊 OCEANPULSE 3D – Global Marine Digital Twin

### Interactive 3D Ocean Data Visualization System

OCEANPULSE 3D is a web-based marine visualization platform designed to explore ocean conditions, monitor marine environments, and understand potential natural hazards through an interactive 3D Earth interface.

The project combines oceanographic data, real-time weather information, interactive visualizations, and predictive hazard indicators to provide a better understanding of global marine conditions.

## 🚀 Key Features

- **Interactive 3D Earth Globe** – Explore different oceans and geographical locations using an interactive 3D interface.
- **Ocean Data Visualization** – View ocean currents, wind speed, wave height, sea surface temperature, and salinity.
- **Multiple Map Views** – Switch between Satellite, Street, Terrain, Hybrid, Dark, and Light map styles.
- **Marine Sensor Network** – Explore simulated and sensor-network representations of ARGO floats, NOAA DART buoys, and other marine observation stations.
- **Historical Data & Forecasts** – Visualize past 24-hour and upcoming 24-hour weather and marine trends.
- **3D Ocean Simulations** – Explore interactive wave, wind, and underwater depth visualizations.
- **Predictive Hazard Engine** – Display cyclone and tsunami/seismic risk indicators.
- **Global Threat Radar** – Monitor earthquake and marine-related information.
- **Location Search** – Search for cities, oceans, sensors, and geographical coordinates.
- **Responsive Interface** – Designed to work across desktop and mobile screens.

## 🌐 Data Sources & APIs

The project integrates publicly accessible data services, including:

- **Open-Meteo API** – Weather and marine forecast information.
- **USGS Earthquake API** – Earthquake information and seismic activity.
- **BigDataCloud API** – Reverse geographical location lookup.
- **World Atlas** – Geographic landmass and country boundary data.

## 💻 Getting Started

You can run the project locally by following these steps.

1. Clone the repository:

   ```bash
   git clone https://github.com/mukundhan-kaizen/OceanPulse-3D.git
   ```

2. Open the downloaded project folder.

3. Locate the main HTML file.

4. Open it using your browser or VS Code Live Server.

5. Make sure you have an active internet connection to load external libraries and API data.

## 🎮 How to Use

1. Open the website to view the rotating 3D Earth.
2. Drag the globe to explore different geographical locations.
3. Select any ocean location to inspect its marine information.
4. Use the layer controls to enable or disable wind, salinity, sensors, coastlines, and hazard visualizations.
5. Explore historical charts and forecasts.
6. Use the 3D wave and ocean-depth visualizers to understand marine conditions.
7. Check the Global Threat Radar for seismic and marine-related information.

Our main objective is to make complex marine information easier to explore and understand through an interactive digital platform. By combining geographical visualization, oceanographic information, and hazard indicators, OCEANPULSE 3D aims to support better awareness of global ocean conditions.
